Capabilities

Where our strength lies

Deep experience in power stages and digital control, with a common set of features across our designs.

Areas of strength

  • Validation of topologies and control methods by simulation
  • Control system design
  • Algorithm development for higher efficiency and reliability
  • Analog, digital and microcontroller / DSP-based hardware design
  • Power circuit development with IGBT, MOSFET and SiC
  • Fully qualified prototype unit development
  • Product support for manufacturing

Common features of our designs

  • Fully digital control with advanced 16 / 32-bit controllers
  • Communication over RS485, Ethernet and USB
  • Event logging with USB host interface
  • Wired and wireless monitoring
  • Ethernet IPv4 / IPv6 with HTTP, SNMP, Telnet and SNTP interfaces
  • GPRS modem connectivity to a central monitoring server
  • Graphic LCD, touch screen and keyboard user interfaces
  • PC-based test system for quick testing and troubleshooting
  • Voice announcement systems
